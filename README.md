# Campus Life

## Déscription
Campus Life est une plateforme fictive destinée aux futurs et nouveaux apprenants de YouCode. À partir d'une maquette réalisée sur Figma, j'ai participé à l'intégration du projet en développant une partie de la page d'accueil à l'aide de HTML5 et CSS3, en respectant le design initial.
## Technologies
- HTML5
- CSS3
